# Portfólio — Marco Antonio

https://portfolio-marco-sepia.vercel.app/

Site estático (HTML, CSS e JavaScript puros), sem build.

## Estrutura
```
portfolio-marco/
├── index.html
├── css/style.css
├── js/main.js
└── assets/marco.webp
```

## Como rodar
Abra `index.html` no navegador, ou sirva a pasta:
```
npx serve .
```

## Paleta
| Uso | Cor |
|---|---|
| Fundo | `#000505` |
| Texto | `#fefcfd` |
| Destaque | `#ff6934` |
| Apoio | `#becce0` |

As cores ficam nas variáveis CSS em `:root` no topo de `css/style.css`.
Fontes (Inter Tight e Allura) vêm do Google Fonts.
